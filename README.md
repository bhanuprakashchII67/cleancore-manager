# CleanCore Business Manager

Free, browser-based prototype for:
- Product prices and stock
- Customer billing/invoices
- WhatsApp bill messages
- Daily/weekly/monthly sales
- Profit calculation using your cost prices
- Customer list
- Enquiry list
- JSON backup

## Important
This version stores data in the browser's localStorage. It is not a cloud database and is not suitable for multi-device use yet. Use Export Data for backups.

Open `index.html` in a browser to run it.

For a production version, connect the app to a secure hosted database/authentication system and add real invoice PDF generation, cloud backups, multi-device login, and website enquiry integration.
